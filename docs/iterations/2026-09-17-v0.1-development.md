## M6 完成结果

- JSON v1.0 以需求文档中的 `tasks/subTasks/dependsOn` 为唯一正式交换格式。
- 导出始终读取完整 SQLite 画板，不受搜索、日期视图和依赖显示开关影响。
- 桌面端通过系统打开/保存对话框选择路径，仅启用 `dialog:allow-open` 和 `dialog:allow-save`。
- Rust 对文件和拖拽文本执行权威解析、版本、结构、唯一 id、真实日期、日期顺序、引用、自依赖和环校验。
- 导入预览显示母任务、子任务、依赖数量和逐字段错误列表；校验失败时禁止导入。
- 覆盖导入必须二次确认，并在单个 SQLite 事务内替换数据。
- 合并导入按 id 更新；缺失 id 时按母任务名称或“子任务名称 + 开始日期”匹配，未匹配项生成新 id。
- 合并时文件未提及的当前任务和子任务保持不动；导入任务的依赖按文件内容更新。
- 文件读取限制为 `.json` 且不超过 10 MB，支持 UTF-8 BOM；导出文件自动补 `.json` 扩展名并写入 BOM。
- 导入完成后重新加载画板、重算排期与冲突，并把视图定位到最早开始日期。
- 浏览器开发模式使用相同 UI 和内存适配器，并通过 Blob 下载，不作为正式桌面存储路径。

- `npm test` 更新为 8 个测试文件、24 个测试通过，其中新增模板展示、复制和可导入性验证。
