## M2 完成结果

- 建立 TypeScript 与 Rust 的母任务、子任务、依赖和视图设置契约。
- 日期统一使用 `YYYY-MM-DD` date-only 语义，按 UTC 日序数运算，避免时区和夏令时偏移。
- 建立母任务排期汇总、依赖环检测和排期冲突纯领域函数。
- 建立 bundled SQLite 初始 migration、外键、索引和 schema 版本保护。
- 建立母任务、子任务、展开状态、依赖和视图设置的业务级 Tauri commands。
- SQLite 通过 Rust `Mutex<Storage>` 持有连接；前端不接触 SQL 或数据库路径。
- 建立 Tauri storage gateway 与测试/浏览器预览使用的内存 gateway。
- 数据库、迁移和 IO 错误映射为稳定错误代码，底层 SQL 和本机路径不直接返回 UI。
- 升级至当前 `rusqlite 0.40.2`，并继续使用 bundled SQLite。

## M3 完成结果

- 实现周、双周、自然月三种日期视图，以及上一周期、下一周期和回到今天。
- 实现真实日期表头、今天线、周末弱化和超出视图任务裁切。
- 左侧任务树和右侧时间线使用同一行模型与统一高度，在同一滚动容器中保持纵向同步。
- 实现母任务汇总条、子任务条和宽视口自动拉伸、窄视口横向滚动。
- 实现母任务新建、重命名、删除与二次确认。
- 实现子任务新增、重命名、改期、清空结束日期和删除确认。
- 实现母任务单项及全部展开/收起，并持久化展开状态。
- 实现母任务/子任务名称搜索和无结果反馈。
- 首次启动为空白画板，提供新建与后续 JSON 导入入口，不写入演示数据。
- 浏览器开发模式使用内存 gateway，桌面构建自动使用 Tauri/SQLite gateway。
- 所有数据修改等待本地存储成功后才更新 UI；失败时保留原状态并显示错误 Toast。

## M4 完成结果

- 双击母任务时间线的具体日期可打开新增子任务表单，并自动预填所选日期。
- 任务条主体使用 Pointer Events 整体拖动，开始和结束日期同步移动，持续天数不变。
- 任务条左右边缘提供拉伸柄，分别调整开始和结束日期，且不能跨越另一端。
- 像素位移统一换算为整数天，半列以下不改变日期。
- 点击/拖动使用 4px 阈值区分，小幅点击继续打开编辑表单。
- 拖动中显示日期预览，松手后只提交一次数据库更新并显示结果 Toast。
- 直接操作先在 UI 中乐观更新；写入失败时恢复原始日期并显示错误。
- 单日任务整体拖动继续保留 `endDate = null`；拉伸为多日后写入明确结束日期。
- 点击任务条和日期表单继续作为键盘及无障碍替代操作路径。
