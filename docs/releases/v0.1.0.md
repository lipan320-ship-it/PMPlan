## 主要能力

- 周、双周、月时间板和真实日期导航；
- 母任务、子任务本地 CRUD 与自动保存；
- 双击日期新增、任务条拖动和两端拉伸；
- 多重前置依赖、SVG 连线、聚焦和冲突警示；
- SQLite 本地持久化和 schema migration；
- JSON v1.0 全量导出、覆盖/合并导入和事务回滚；
- AI 导入模板展示、一键复制和格式约束提示；
- 完全离线运行，不需要账号或服务器。
