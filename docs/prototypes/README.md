## 使用边界

该文件用于参考页面布局、色彩和部分交互，不是可发布应用，也不是正式需求来源。

已知边界包括：

- 使用 Google Fonts 与 Tailwind CDN，无法保证完全离线；
- 包含硬编码演示数据和与当前范围不一致的云同步文案；
- 状态主要存在页面内存中，不具备正式数据持久化；
- 单文件结构不适合继续承载生产功能和测试。

后续实现应从需求文档和 ADR 建立正式工程，不直接在该 HTML 文件上继续堆叠产品代码。原型中被采用的视觉或交互方案需要在正式组件中重新实现和验证。
