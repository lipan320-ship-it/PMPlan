# 工作规划时间板 v0.1 使用指南

## 安装与启动

1. 运行 Windows NSIS 安装程序。
2. 按安装向导完成安装并启动“工作规划时间板”。
3. 应用安装完成后可以完全断网运行，不需要账号或本地服务器。

Windows 可能对未签名的内部测试安装包显示来源提示。正式对外分发前应配置代码签名；不要通过关闭系统安全功能来规避提示。

## 第一次使用

首次启动为空白画板，不包含演示任务。可以：

- 点击“新建母任务”，从第一项计划开始；
- 点击“导入模板”，复制 JSON 示例给 AI，让 AI 把现有文字规划整理成可导入文件；
- 点击“导入 JSON”，恢复或迁移已有规划。

如果应用升级前已经在 SQLite 中保存过未命名规划，首次启动会提示“另存为 JSON”。可以立即选择路径建立项目文件，也可以暂缓迁移并继续使用未命名工作区；暂缓不会清空原 SQLite 数据。

## 项目文件与最近打开

### 打开、切换和新建

- 点击“打开项目”，选择一个 `.json` 文件。应用会先校验文件，再切换到该项目；打开项目不会弹出“覆盖 / 合并”导入选项，也不会改写原项目。
- 点击“新建项目”，选择保存路径。应用先写入合法的空 JSON，写入成功后才切换到新项目；取消对话框或写入失败时，当前项目保持不变。
- 项目选择器显示当前文件名和父目录；“最近项目”最多保留 8 个路径。成功打开、新建或另存为后会置顶，重复路径只保留一条。
- 文件被删除、移动、拒绝访问或 JSON 无效时，最近列表保留该条目和失效原因。可以点击“移除最近记录”清理条目；这个操作不会删除源文件。

### 启动恢复

应用重启时优先打开上一次成功打开的项目，并恢复该路径的视图设置。如果路径失效，应用保留失效记录并进入项目选择入口，不会创建空规划覆盖原路径。

### 自动回写和保存状态

打开项目后，对任务、子任务、日期、依赖、排序、展开状态的修改都会自动回写当前项目的同一路径 JSON。SQLite 负责当前编辑事务和恢复缓存，JSON 是命名项目的可见规划文件。视图设置（视图模式、锚点日期、依赖显示、任务列宽和排序方式）按项目路径保存在应用元数据中，不写入 JSON。

工具栏会显示 `已保存`、`保存中`、`未保存` 或 `外部已修改`。写入前应用同时检查文件修改时间和内容哈希：

- 如果文件与上次成功读写时一致，应用以同目录临时文件原子替换原 JSON。
- 如果文件被外部修改或删除，应用暂停回写，不会静默覆盖。选择“重新加载”会在确认后放弃当前未保存缓存并读取外部文件；选择“另存为”会把当前缓存写入新路径并切换项目；选择“取消”则保留未保存状态。
- 如果目录只读或写入失败，当前缓存仍保留，界面不会提示保存成功；可以重试或另存为。

## 规划任务

### 母任务

- “新建母任务”创建一组工作。
- 点击母任务名称进行重命名。
- 在新建或编辑母任务时填写一个可选标签；标签会以徽标显示在母任务行中。
- 工具栏可切换“手动顺序 / 按标签分组”。标签视图按标签名称分组，组内沿用手动顺序，“无标签”固定在最后；该视图不改变手动排序，也不能拖动母任务。
- 点击展开箭头显示或隐藏子任务。
- 删除母任务会同时删除其子任务及相关依赖，操作前必须二次确认。

### 子任务

- 点击母任务行中的“+ 子任务”添加工作。
- 双击母任务时间线中的某一天，可快速新增并自动带入该日期。
- 点击任务条或左侧子任务名称，编辑名称、开始日期和结束日期。
- 结束日期留空时按单日任务处理。
- 删除子任务前需要二次确认。

### 直接调整日期

- 拖动任务条主体：整体移动开始和结束日期，持续天数不变。
- 拖动任务条左侧边缘：调整开始日期。
- 拖动任务条右侧边缘：调整结束日期。
- 所有操作按完整日期吸附；松手后自动保存。

## 时间视图

- 时间轴是一段连续日期，起点可以是任意一天，不按周首或月初对齐，因此同一个窗口里能看到 10/31 与 11/1 这样的跨月衔接。
- 周 / 双周 / 月是日期密度档位，可见天数由窗口宽度决定。
- “季度总览”在同一宽度中展示连续 90–92 天，以月份带和周刻度帮助全览；拖动整条子任务可按天平移并保持持续天数，拖动左右边缘可分别调整开始和结束日期，点击任务条仍使用原有日期弹窗精确编辑。
- 在时间轴空白处按住左右拖动即可连续平移；触控板或鼠标横向滚轮同样可以平移。
- 使用左右箭头按约半个窗口步进，点击“今天”把当天定位到窗口靠前位置。
- 平移会静默保存，不弹提示；重新打开后停在原位置。
- 周末使用浅色背景，今天使用高亮日期和竖线；表头上方的月份带标明每个日期所属月份。
- 搜索框可按母任务或子任务名称过滤。
- 搜索框也会匹配母任务标签；标签排序选择会自动保存并在下次启动时恢复。

## 需求依赖

1. 点击母任务行中的“依赖”。
2. 搜索并勾选一个或多个前置母任务。
3. 保存后，时间线显示“前置任务 → 当前任务”的箭头。

系统禁止自依赖和循环依赖。若后置任务开始日期不晚于前置任务结束日期，只显示警示，不会自动改变任何日期。可用顶部“显示依赖”开关隐藏连线，依赖数据不会被删除。

## JSON 项目文件、导入与导出

“打开项目”和“导入 JSON”是两种不同操作：打开项目会切换到所选 JSON 并绑定自动回写路径；导入 JSON 只把数据应用到当前项目，仍然先预览并选择覆盖或合并。导出 JSON 始终是另存副本，不改变当前项目身份。

### 导出

点击“导出 JSON”，选择保存位置。导出始终包含全部母任务、子任务和依赖，不受当前搜索、日期视图或依赖显示开关影响。

默认文件名：

```text
工作规划时间板_YYYY-MM-DD.json
```

### 导入

可以点击“导入 JSON”选择文件，也可以把 `.json` 文件拖入应用窗口。

- 覆盖：替换当前全部规划，开始前需要再次确认。
- 合并：按 id 更新已有任务，新任务追加，文件没有提及的当前任务保留。

应用会先展示文件版本、数量和错误列表。校验失败时不会写入任何数据。导入完成后，画板定位到导入数据中的最早开始日期，并按当前项目的自动回写规则写回当前项目 JSON；未命名工作区在另存为前只写 SQLite。

### 使用 AI 整理导入内容

1. 点击顶部工具栏的“导入模板”。
2. 点击“复制模板”，将模板和原始规划一起发给 AI。
3. 要求 AI 替换示例内容，只返回 JSON，不添加 Markdown 代码块。
4. 将结果保存为 `.json` 文件，再通过“导入 JSON”导入。

模板中的母任务和子任务 `id` 必须各自唯一；`dependsOn` 只填写前置母任务的 `id`；日期使用 `YYYY-MM-DD`，单日任务的 `endDate` 填 `null`。弹窗中的模板本身已通过当前覆盖导入规则校验。

## 本地数据位置

命名项目的规划数据保存在用户选择的 JSON 路径。应用本地目录保存事务缓存、最近项目索引和按项目路径隔离的视图设置：

```text
%LOCALAPPDATA%\com.pmplan.desktop\pmplan.sqlite3
```

同目录中的 `pmplan.sqlite3-wal` 和 `pmplan.sqlite3-shm` 是 SQLite 运行文件。应用运行期间不要复制、修改或删除这些文件。

建议通过“导出 JSON”进行日常备份和迁移，不直接操作数据库。卸载前如需保留未命名工作区，请先通过“新建项目”或“另存为”写出 JSON；移除最近记录不会删除项目文件。

## 当前版本边界

v0.1 不包含账号、云同步、多人协作、完成状态、进度百分比、自动排程、工时统计、人员负荷或自动备份。
